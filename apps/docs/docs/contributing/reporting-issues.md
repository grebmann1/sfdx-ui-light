# Reporting Issues and Requests

Use GitHub issues to report bugs, request features, and discuss improvements.

## Where to file issues

- Issues page: [sf-toolkit-web/issues](https://github.com/grebmann1/sf-toolkit-web/issues)

## Bug report checklist

Please include:

- clear summary of what is broken
- expected behavior vs actual behavior
- exact reproduction steps
- relevant environment details (OS, Node version, browser, route)
- logs, screenshots, or screen recordings when possible

## Feature request checklist

Please include:

- the problem you are trying to solve
- current workaround (if any)
- proposed UX or API behavior
- why this would help your workflow

## Security issues

Do not post sensitive security details in public issues.
If you discover a security vulnerability, contact the maintainers privately first.

## Improve issue quality

Before opening a new issue:

- search existing issues for duplicates
- verify against latest `main`
- check docs in `/docs` and known fixes in troubleshooting pages

# VS Code Workflows

SF Toolkit includes a VS Code-style workbench experience for Salesforce tasks.

## What you can do

- browse org resources and metadata
- run data and query operations
- use extension-powered workflows in one UI surface

## Recommended flow

1. Connect an org from the app.
2. Open the workbench-oriented tools.
3. Run metadata or query tasks and review results.

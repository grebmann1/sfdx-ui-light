# CLI Usage

The repository exposes npm scripts for build, validation, and runtime workflows.

## Common commands

```bash
npm run start:dev:web
npm run build:web
npm run start:prod:web
```

## Website and docs commands

```bash
npm run ui:dev
npm run docs:dev
npm run build:web:all
```

## Quality checks

```bash
npm run lint
npm run check
npm run validate
```

# Workbench Documentation

Workbench is a Salesforce productivity platform that ships as a **web app**, a **browser extension**, and an **Electron desktop app**. All three surfaces share the same LWC frontend, an embedded VS Code workbench, and an AI agent for Salesforce-oriented tasks.

## What this documentation covers

- **Getting started**: install prerequisites, configure OAuth variables, and run local services.
- **Architecture**: high-level overview of the monorepo, packages, iframe bridge design, and multi-surface builds.
- **App workflows**: run SOQL, inspect metadata, test APIs, and validate org changes.
- **Workbench workflows**: use extension-driven Salesforce tooling in the embedded VS Code surface.
- **Operations and support**: troubleshoot local issues, review privacy details, and contribute changes safely.

| Route | Surface | Purpose |

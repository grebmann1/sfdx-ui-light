# Workbench Documentation

Workbench is a Salesforce productivity toolkit that ships as a **Chrome extension** (recommended) and a **desktop app** (in development). All surfaces share the same LWC frontend, an embedded VS Code workbench, and an AI agent for Salesforce-oriented tasks.

It is the modern replacement for **Salesforce Workbench** and **Benchpress**.

## What this documentation covers

- **Getting started**: install the extension or run locally, configure OAuth, and connect your org.
- **Architecture**: monorepo layout, packages, iframe bridge design, and multi-surface builds.
- **VS Code integration**: embedded editor, extension bridges, and parity with upstream Salesforce extensions.
- **AI Agent**: provider setup, capabilities, and tool reference.
- **Operations and support**: troubleshoot issues, review privacy details, and contribute changes.

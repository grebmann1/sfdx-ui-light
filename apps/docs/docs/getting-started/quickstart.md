# Quickstart

This guide gets you from clone to useful workflows in a few minutes.

## 1. Install and run

```bash
git clone https://github.com/grebmann1/sf-toolkit-web.git
cd sf-toolkit-web
npm install
npm run start:dev:web
```

## 2. Open the key pages

- Website: `http://localhost:3000/welcome`
- Docs: `http://localhost:3000/docs`
- Main app: `http://localhost:3000/app`

## 3. Connect your Salesforce org

1. Open `/app`.
2. Go to the connection or org area.
3. Complete OAuth login.
4. Validate that org details load successfully.

## 4. Run your first tasks

- Execute a SOQL query.
- Explore metadata and objects.
- Open API tools and test a request.
